# Генератор резюме

Веб-приложение для создания резюме с предпросмотром и экспортом в PDF.

## Демо

https://fumiko8.github.io/resume-generator/

## Функционал

- Ввод личных данных (ФИО, должность, зарплата, контакты)
- Добавление/редактирование/удаление опыта работы
- Добавление/редактирование/удаление образования
- Добавление/удаление ключевых навыков
- Автосохранение в localStorage
- Экспорт резюме в PDF

## Технологии

- HTML5 / CSS3
- JavaScript (ES6+)
- html2canvas + jsPDF — экспорт PDF
- localStorage — хранение данных

## Запуск

Открыть `index.html` в браузере или перейти по [ссылке](https://fumiko8.github.io/resume-generator/)
